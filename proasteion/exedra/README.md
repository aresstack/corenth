# Exedra

Local UI adapter.

Exedra is the local user-facing adapter. It is intended for the workstation UI, such as a Swing-based interface, and should translate user actions into stable application-level requests.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.

# Katagogion

Plugin adapter and sandbox.

Katagogion is the plugin lodging house. It is intended for controlled plugin execution and MCP-style integrations such as spreadsheet or tool-specific importers.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.

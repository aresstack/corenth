# Deigma

Harbor parser layer for transport and file structure.

Deigma inspects and structures incoming cargo. It parses transport or file-level structures such as CSV, Excel schemas or exported formats and turns raw streams into usable virtual resources. Deep source-code semantics belong to Propylaea, not Deigma.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.

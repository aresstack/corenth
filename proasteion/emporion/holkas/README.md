# Holkas

Connection layer for raw virtual resources.

Holkas contains connection implementations. A Holkas brings raw resources into the harbor through protocols such as local files, HTTP, Outlook, SharePoint or mainframe connections. It should not perform semantic parsing.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.

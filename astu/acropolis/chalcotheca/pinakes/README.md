# Pinakes

Semantic catalog for embeddings and reranking preparation.

Pinakes is the semantic catalog. It is intended for embeddings, vector-oriented lookup, semantic similarity and local reranking preparation where the environment allows it.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.

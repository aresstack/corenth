# Anagraphai

Lexical full-text register.

Anagraphai is the inventory register for exact and keyword-based search. It is the natural home for Lucene-backed indexing, tokenization, metadata fields and classic full-text retrieval.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.

# Chalcotheca

Resource archive, cache and lifecycle manager.

Chalcotheca is the bronze archive of Corenth. It owns resource metadata, cache state, lifecycle information and the transition from raw incoming resources to governed, searchable material.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.

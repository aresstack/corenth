# Propylaea

Gate for deep source-code parsing and language abstraction.

Propylaea handles language-aware parsing. It is intended for source-code analysis, compiler-generator based parsers and universal program-structure abstractions such as caller/callee relations, control flow and data access.

## Role in Corenth

This module is part of the Corenth Gradle multi-project architecture and keeps its Greek name intentionally. The name marks a boundary in the architecture and should not be replaced by a generic technical term.
